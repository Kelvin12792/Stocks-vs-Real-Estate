# Fact Check Log

## Purpose

This file tracks every factual claim made in the manuscript — statistics, percentages, historical events, named studies, regulatory figures, and quoted data points. Each claim is logged with its source, source date, verification date, and current status. The goal is to ensure that no unverified or outdated fact reaches a published edition.

This log is updated continuously as chapters are drafted and revised. Before any edition goes to final review, every row in the Claims Log must have a status of 🟢 Verified or 🔵 Updated for new edition.

---

## Status Key

| Symbol | Meaning |
|--------|---------|
| ⬜ | Not yet verified — claim has been written but source has not been confirmed |
| 🟡 | Source identified — a plausible source has been noted but the claim has not been cross-referenced |
| 🟢 | Verified — claim confirmed against primary source and at least one secondary source |
| 🔴 | Incorrect / Outdated — claim is wrong or no longer accurate; must be corrected before publication |
| 🔵 | Updated for new edition — claim was previously verified but has been refreshed with current data for a new edition |

## Verification Standards

All fact-checking for this book must adhere to the following standards:

1. **Use primary sources.** Data must be traced to its origin — government databases (e.g., FRED, IRS, BLS, Census Bureau), peer-reviewed academic papers, or official institutional reports. Do not cite an author citing another source; go to the original.

2. **Cross-reference with at least one secondary source.** Every verified claim must be confirmed by a second independent source. If two credible sources conflict, note the discrepancy in the Notes column and flag for editorial review before using the figure.

3. **Date-stamp every verification.** The Verified Date column must be filled in with the date the fact-checker confirmed the claim (format: YYYY-MM-DD). A blank Verified Date means the claim has not been verified, regardless of status symbol.

4. **Flag items older than 3 years.** Any claim whose Source Date is more than three years prior to the current publication date must be reviewed to determine whether more recent data exists. If more recent data is available and meaningfully different, the claim must be updated and the row status changed to 🔵. If the older figure is still the most authoritative available, note this explicitly in the Notes column.

5. **Distinguish between point-in-time and durable facts.** Some facts (e.g., historical market crash dates, legislative enactment years) are permanent. Others (e.g., current mortgage rates, median home prices, index fund expense ratios) change frequently and must be re-verified before each edition.

6. **Document conflicting sources.** If sources disagree, log all variants in the Notes column with attribution. Do not silently select one figure; surface the disagreement for author and editor review.
